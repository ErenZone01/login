COMMANDE POUR EXECUTER LES DEMANDES SUIVANTES :

## 1 inode :

L'inode est une structure de données qui contient des informations sur un fichier ou un répertoire sur le système de fichiers Linux. Pour obtenir le numéro d'inode d'un fichier, utilisez la commande suivante :

```bash
ls -i <nom_du_fichier>
```
## 2 id user : 

L'ID utilisateur (UID) est un identifiant unique attribué à chaque utilisateur sur le système. Pour afficher l'UID de l'utilisateur actuellement connecté, utilisez la commande :

```bash
id -u
```

## 3  pid d'un progamme : 

Le PID (Process ID) est un numéro unique attribué à chaque processus en cours d'exécution sur un système Linux. Pour obtenir le PID d'un programme spécifique comme bash, utilisez la commande pidof :

```bash
pidof bash
```
